# C++ Algorithms and Data Structures

Coursework projects on recursion, algorithms and abstract data types in C++.

| Project | Topics |
|---|---|
| [Recursion](Recursion/) | Recursive problem solving: subsequences, combinations, number conversions, Sierpinski fractal, Flesch–Kincaid readability |
| [Collections](Collections/) | Word Ladder (breadth-first search) and a Markov-chain Random Writer |
| [Boggle](Boggle/) | Word game with recursive board search |
| [Priority Queue](Priority%20Queue/) | Three priority queue implementations: vector, singly linked list, doubly linked list |
| [Huffman](Huffman/) | Huffman encoding for file compression |
